Documentation
=============

Airsonic-Advanced documentation lives in this repository:

- [README](../README.md) — installation, Docker, getting started
- [Advanced Topics](ADVANCED.md) — first start, media organization, web UI, configuration reference, reverse proxy, jukebox, clients, troubleshooting
- [Contributing](CONTRIBUTING.md) — guidelines, building from source, pull request expectations

Documentation for upstream Airsonic is stored in a [dedicated repository](https://github.com/airsonic/documentation) and can be browsed on [the Airsonic website](https://airsonic.github.io/docs). Most of it still applies to Airsonic-Advanced; where behaviour differs, [Advanced Topics](ADVANCED.md) is authoritative.
